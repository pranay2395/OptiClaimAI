USER WORKFLOW
================================================================================

SCENARIO 1: With PDF Upload (Fast Path - 2-3 minutes)
1. Navigate to "Submit Claim" tab
2. Click "Upload claim PDF" button
3. Select PDF from computer
4. Wait for extraction (spinner shown)
5. Form auto-populates with ✅ indicators
6. Review and optionally edit fields
7. Click "✅ Submit Claim" button
8. Validation runs automatically
9. Claim stored to database
10. Done! ✅

SCENARIO 2: Without PDF (Standard Path - 5-10 minutes)
1. Navigate to "Submit Claim" tab
2. Skip PDF upload section
3. Manually fill all form fields
4. Click "✅ Submit Claim" button
5. Validation runs automatically
6. Claim stored to database
7. Done! ✅

SCENARIO 3: Problematic PDF (Fallback Path - 5-10 minutes)
1. Navigate to "Submit Claim" tab
2. Upload scanned/encrypted PDF
3. See message: "This PDF appears to be scanned/image-based"
4. Manually fill form fields
5. Click "✅ Submit Claim" button
6. Validation runs automatically
7. Claim stored to database
8. Done! ✅
