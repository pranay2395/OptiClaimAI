## 🎓 LESSONS LEARNED

1. **Canonical Data Model** - Single source of truth dramatically simplifies multi-input problem
2. **Subprocess-Based AI** - Ollama integration simpler than HTTP APIs + no key management
3. **Regex NLP** - Sufficient for healthcare domain, no expensive transformers needed
4. **Graceful Degradation** - Optional AI works perfectly for MVP
5. **Session State** - Critical for Streamlit multi-step workflows
6. **Deterministic Validation** - Rules engine more trustworthy than ML for critical decisions
